## 2. 只读集群核验（集群登录节点，Bash）

在你已有的集群终端完整运行下段即可。不会安装、下载或启动 GPU：

```bash
hostname
date -Iseconds
for p in /home/share/czy /home/u2025010462/share/czy/swt /home/u2025010462/share/czy/swt/my_pape/STC; do
  if [ -e "$p" ]; then realpath "$p"; else printf 'MISSING %s\n' "$p"; fi
done
MODEL_DIR=/home/u2025010462/share/czy/swt/my_pape/STC/hf_cache/llava-onevision-qwen2-0.5b-ov-hf
if [ -d "$MODEL_DIR" ]; then
  printf '\nMODEL_FILES\n'
  find "$MODEL_DIR" -maxdepth 1 -type f -printf '%f %s bytes\n' | sort
  printf '\nMODEL_LINK_TARGET\n'
  realpath "$MODEL_DIR"
fi
printf '\nSLURM\n'
command -v sbatch
sinfo -h -o '%P|%a|%l|%D|%G'
squeue -u u2025010462
```

回传短输出即可，先判断路径、文件与资源。不要打印完整环境变量、SSH 私钥或包含凭据的配置。拿到核验结果后才创建新实验目录；不使用旧环境安装新依赖。

## 3. 轻量备份（本机 PowerShell）

```powershell
& 'E:\VIT Model\backup.ps1'
```

输出一个 zip 及其 SHA256，并逐项校验压缩包内容。白名单包括文档、配置、项目代码、固定来源、依赖锁、小型 JSON/日志与模型/素材的文本 manifest；不含权重、实际图片/视频、环境或凭据。输出在源文件夹 A 的 `流式视频模型架构学习_交接备份`。每文件上限 1 MB，总计上限 10 MB；源目录其余资料不复制。

备份为不可覆盖的时间戳快照，每次关键里程碑或交接时运行。脚本不自动删除旧包；包的体积本来很小，如后续数量过多再明确整理。

## 4. 恢复和一致性

1. 解压到空目录，读取内部 MANIFEST.sha256.json。
2. 对清单每个 Path 执行 Get-FileHash -Algorithm SHA256，与 SHA256 比较。
3. 读总纲的更新时间、证据等级和下一步；核对真实运行结果是否另外归档。
4. 集群代码以后可以用 scp 下载回本地，优先下载代码/配置/小型结果；模型只记录来源、revision 和哈希，不为了备份再复制数 GB 权重。
5. 将来正式提交作业时必须同时记录 job_id、输出目录、squeue/sacct/日志查询命令；本轮没有 job_id，不能伪造查询占位符。
6. S4备份不包含.git。恢复正式Git时，克隆固定起点到新的个人目录、建立自己的分支，再从包内`code/qwen35-streaming-s4`逐文件恢复并按source_tree.json核对；不覆盖同学目录。tracked_changes.patch是模型/许可说明的审阅差异，不包含新增模块，不能只应用patch就声称完整恢复，也不能恢复文件后重复应用同一patch。原SNAPSHOT.json仍表示来源，实际候选内容以run provenance及交付source_tree哈希为准。
