# 两阶段读取：纠正了什么，又在哪一步出错

2026-10-15 固定实验结果。持续进度只看《实验总纲.md》，不改旧综合汇报。

**这轮出现了局部纠错，也出现了新错误。候选继续保留研究资格。** 不能用上轮简单题双满分淘汰它，也不能只展示这轮一个成功案例就把它设成默认。

## 为什么重新设计实验

用户指出：直接读取已经答对全部简单题，候选没有提升空间。这是正确的。上轮四张新照片只能验证两种流程都能正常完成简单有无动物判断，不能判定候选无用。

本轮事前固定完整12题，加入可能出错的主体识别、细节和早期内容查询。题目、真值、别名表在真实运行前冻结。先保留全部直接读取结果，再按预定规则把其中的错误题组成困难子集；同时检查原本答对的题有没有被候选带错。**困难子集按基线结果选出，不能当作总体准确率。**

六个来源帧对来自熟悉的真实视频：狗、猫、鸟、片头、片尾、人手洗手。12题共享来源，不是12个独立样本，更不是新素材泛化评估。此处有意利用熟悉失败线索定位问题，不能称盲测榜单。

## 改了什么

新独立实验 `experiments/readout_challenge_v1`，复用完整48Token的外部帧对特征，没有压缩、训练或网络层修改。六来源各视觉编码一次，主状态reset后保留独立证据；两条路径都从新问答上下文读取同一证据：

```text
直接：完整视觉特征 + 固定问题 → 答案
候选：同一视觉特征 → 中性描述 → 新纯文字上下文 + 同一个问题 → 答案
```

每题交替先后，两臂答案上限均24Token，描述也24Token。第二步只收到实际生成的描述与问题，不含真值、案例ID、素材名、图像或视觉问答缓存。

四道首段题把不同视频的完整节点组合为狗→猫、猫→狗、鸟→狗、文字片头→狗。原视频真实PTS另记；节点复制后明确赋合成时段0..1、2..3，保留特征值和二维坐标。这是受控顺序诊断，不冒充一段真实连续视频，也没有自动事件检索。

固定中性描述问题：`Describe the visible content in time order in two short sentences.`

文字读出提示如下，问题本身与直接路径相同：

```text
Read the description and answer the question using only this description. If it lacks the requested information, answer uncertain.
Description: {实际描述}
Question: {固定问题}
```

主评分使用事前别名表，去首尾空白、小写、一个句末英文句号。例如dog/a dog、bird/pigeon、black-white/black and white。整句解释不事后自动抽取成标签；严格标签格式另记。语义正确但格式失败的情况会单独说明，不包装成事实错误。

## 有价值的发现：把错误定位到具体步骤

**1．洗手题给出了一个真正的纠错案例。**

直接问非人动物，模型答dog。中性描述却生成：

> A person is washing their hands in a sink with soap and water.

文字阶段据此答none，与画面相符。这说明在这个条件下，两阶段组织有能力纠正直接读取错误，候选值得继续研究。它还不能证明“消除了问题暗示”这个原因，因为描述提示、上下文和计算步骤同时改变了。

**2．背景人物题定位到了文字读出错误。**

描述是：

> A white dog is seen in the foreground, while a woman stands in the background.

图中确实有人；问题是狗后面是否有人。直接答yes，而第二步答no。信息已经在中间描述里，错误发生在描述到答案这一步。增加森林容量或降低压缩率，都没有直接针对这个问题。

**3．猫颜色题属于接口问题，不能算看不懂颜色。**

描述和最终整句回答都明确写了black and white。失败在于没有输出限定标签。预登记主分数仍记失败，同时人工审查注明语义正确。这提示后续应把输出格式约束作为独立变量验证；不能事后改解析器来改写本轮分数。

**4．小鸟与首段题仍有前一步的信息问题。**

单独鸟帧的中性描述误成有人从建筑物跑出，后面的文字阶段无法恢复缺失的鸟。鸟→狗描述又写成狗在屋顶跑；文字→狗描述只写狗，丢了开头的文字场景。完整特征没有压缩，这些失败不能全部归咎于压缩。中性描述本身也会遗漏时间段或混入错误细节。

猫→狗的描述还把背景人物混到了猫附近。首段答案cat正确，也不足以证明整段时间关系描述完全正确。

## 下一步建议

**继续保留候选，先修清文字读出这一环，再做新的对照。**

最小而有区分度的下一段是固定本轮已经生成的描述，仅检验文字读出器：能否按要求输出标签、能否从背景有人得出yes、描述缺信息时能否明确uncertain。把格式改动与语义判断改动分别测，不能靠格式修复假称识别变强；之后回测完整12题的纠错和引入，再用独立素材确认。

对旧内容的描述遗漏，需要另做时间段选择/分段描述的对照。先把“存了什么”“描述保留了什么”“文字阶段如何使用它”分清楚，再判断是否值得接入森林或问题相关取回。现有一项局部纠错是继续研究的理由，整集净标签分数较低是暂不默认接入的理由；两项证据同时保留。
