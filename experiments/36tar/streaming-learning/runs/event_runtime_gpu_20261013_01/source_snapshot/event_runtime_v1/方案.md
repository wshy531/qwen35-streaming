# 单一可选事件文件入口：收敛与持续写入

复用冻结event_memory_v1与event_retrieval_v1，空间Token不压缩、阈值显式参数，默认视频CLI保持。入口支持任意本地视频路径、开放current/history问题、FPS、时长/帧上限、主Token预算与个人分支规则；当前视觉画布固定192×256/48Token是基座协议限制，不假称任意网格。银行不再有8对上限，仍有144Token/592704B硬上限和最多2闭组。只有一个候选银行。

主会话容量达到上限时，完整新帧对写入前先reset主状态、外部银行张量保持；输入全局ID/PTS仍严格递增。问答分别current/group/exact，显示实际代表区间与组范围，不根据问题文字猜检索目标。没有新完整帧对时current拒绝；只剩组范围不能作精确查询。EOF奇数帧明确记录未编码并释放，不复制补帧，最终current代表最新已编码对而非该未编码单帧。固定题目参数超限预先拒绝。

CPU契约包含100帧/多容量reset、查询隔离、主reset后历史/当前边界、EOF奇数不合成、全局因果/非法输入、主写入失败不提交外部、关闭/所有权；新proof绑定源码与配置/模型/实际源帧像素/模板。

本轮clean_hands原文件、1FPS/max40帧/25秒、主256Token/64问题32回答reserve、每4对current、末尾current（不重复同一版本）、第一个闭组history，另显式未来和原0.5秒exact安全查询。最多20视觉/7QA/224生成/280语言/360秒、一载入；源文件≤64MiB，选取≤120帧/≤600秒/FPS≤4，文件只顺序读取已到达PTS。原RAM3GiB/GPUfree5.5GiB/转换2GiB门禁，FP32；QA日志显示bank/主状态摘要不变。CPU tiny只机制，真实GPU能力失败完整保留。

驻留银行≤592704B、pending RGB147456B、主会话最多256Token，QA独立最多512；CPU特征临时≤4MiB，帧相关临时RGB≤1MiB估计并登记，Python对象/模型参数/原解码器内部不包含在这些小张量数字中。峰值allocated/reserved另测。reader在到达帧/时长上限或EOF关闭，无物理摄像头/集群/训练，默认核心不改。GPU不是实时墙钟播放，有限顺序文件输入不代表无限运行或长期准确记忆。
