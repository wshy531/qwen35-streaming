Original JPEGs are unchanged and excluded from Git/backups. Runtime converts RGB and letterboxes to256×192, then repeats each still four times for a synthetic temporal control; this is not natural motion video. Credits, URLs, original SHA1/SHA256 and lengths are in asset_manifest.json. Black/white image is used for light/dark fur, not hue. Backgrounds and poses differ between photographs, so this is a same-species check, not an isolated recoloring intervention.
