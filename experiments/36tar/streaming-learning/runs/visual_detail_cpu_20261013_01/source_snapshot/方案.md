# 原像素、两次缩放与视觉分辨率诊断

上一同帧诊断三路径8例同答同错，不能归因特征读取。本实验固定这8对和问题，检查进入模型前的图像细节。

- A old_two_stage：原帧先PIL thumbnail最长边256，再fit_canvas到192×256，重建并核对上一CPU/GPU的像素/Token/位置fingerprint。
- B direct_small：原帧直接fit_canvas到192×256，与A同48视觉Token、同位置/题目。
- C direct_large：原帧直接fit_canvas到384×512，192视觉Token。4倍视觉Token/patch工作量是代价，不能作同预算收益。

原帧按已有proof的source_frame_id从原视频顺序解码，source_pts必须匹配，保留宽高比/黑边。官方processor do_resize=False、do_sample_frames=False；整数毫秒/fps1000仅PTS载体，不是源FPS。原源码整段FP32 IEEE/math，512总Token/32输出，所有题目与此前同一。C保留更多可用像素，但不保证必然答对；B也可能因插值变化而改变答案。

CPU：24输入检查grid/视觉Token/四轴位置、A旧fingerprint重建、B与A文字及位置同一、C4倍占位；同权微型原/当前fresh末logits固定atol=rtol=1e-4，不调整门槛，随机输出不作能力证据。每次首跑先保存全部新源码快照。

GPU：最多1载入/24视觉/24问答/768生成/792语言forward/360秒；RAM≥3GiB/GPUfree≥5.5GiB/FP32转换余量≥2GiB，单模型/单输入臂；原始两帧RGB≤32MiB、小图材料≤8MiB；不存完整视频或大Tensor。源解码/预处理/模型墙时分开，逐输入计Token/patch，查询成本或显存峰值不是长期稳定性证据。固定A先于B/C，记录这是诊断，不是交错性能基准。

保留全部原答、EOS/预算截止及A原生成/logits身份控制；CPUproof校验代码/模型/素材/源PTS/像素/参数/布局。熟悉素材定位，不是泛化准确率。无训练、摄像头、集群、Git上传；新进度只维护根实验总纲，综合汇报不更改。
