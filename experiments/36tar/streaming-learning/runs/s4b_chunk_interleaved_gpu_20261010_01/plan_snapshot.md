# 32计算块候选：交错顺序与多长度扩展预登记

2026-10-10。用户“继续”授权接续前述32候选交错/多长度验证。本文件冻结实验方案，进度仅总纲。既有60源文件只读，新实验独立模块/run，不改原默认64、视觉候选或BF16设置；不训练、不用集群、不生成答案。

五组固定输入：精确31、65、129Token的同源文本前缀（合成长度探针，非自然能力题）；洗手前4帧/猫前6帧，真实PTS 1 FPS、明确192×256、时间单元2/3。视频整段/逐对像素、Token、四轴位置先核验同一，再只编码一次固定时间单元视觉候选，64/32语言共用同一实际特征。文本布局分别[7,24]、[7,31,27]、[7,31,32,59]，视频布局固定提示+各帧对，不造未来输入。所有前缀+固定Q1后缀34+预定HANDS首Token≤256，Token与帧指纹冻结。

每组两模式各1次预热（64→32，排除计时统计）+6次正式测量；正式顺序64→32和32→64各3次。每轮、每模式新建空状态：完整1次及全部增量布局各n次，分别同步墙钟/CUDA事件（含提交间隙），模式安装/检查/比较/CPU搬运不计入语言阶段。每轮比较：32全部完整logits/全部最终缓存对64；两模式各增量最后新增块/全部缓存对自身完整。所有正式轮数值也检查，不只预热。每组预热的两问题分支检查问题logits、预定Token logits/全部最终分支缓存跨模式；主缓存逐位不变、存储独立及全部reset空。问题只用于数值，不计答案正确率。

保持原严格logits max≤0.01、mean≤0.0001、RMS≤0.0003及allclose atol/rtol1e-4；key/value/conv/recurrent四类全部缓存allclose1e-4。不通过的数值仍记录、其他预登记组继续收集；最终摘要all_strict_controls_passed=false并标失败，不能放宽门槛或只看argmax。协议异常/资源超限则立即停止并保留partial。成功统计仅有限输入，不证明跨设备/BF16/长时间/所有输入的收益；各组单列中位数、范围、逐轮配对比值，不能把不同组分母合成通用正确率。

真实预算：单次模型载入、本机RTX4060 Laptop 8GiB、FP32 IEEE matmul/conv + math SDPA；2视觉（2+3单元×50 Linear=250内部投影），314语言（7轮×2模式×[5完整+16增量]=294，加5组×2模式×2分支=20），其中304多Token调用×18GDN=5472被包装后备调用、10单Token递归调用×18=180（后者未改，不计包装）。生成0，600秒看门狗。CPU须根据真实config的18GDN和50视觉Linear验证这些公式，不能用微型深度估计。

内存：载入前GPU free≥5.5GiB及RAM≥3GiB；转FP32前二者≥2GiB；不降低门槛。预计CUDA allocated≤6GiB，记录allocated/reserved总峰值；额外留存特征硬限8MiB，每组最大589824字节。最多留同轮两模式完整/增量对照和预热分支，逐轮/逐组释放，语言logits/cache/比较工作区计入CUDA总峰值。不保存Tensor、素材副本或新环境。方法/包装/钩子正常与异常恢复；异常traceback可能引用GPU对象到进程退出，明确记录而不虚称立刻释放。显式ChunkRule仅包裹torch后备函数；默认64不动。

CPU微型预检做全五组/全顺序契约、真实config预算、零调用预算异常恢复；CPU随机权重不是模型能力/速度证据。启动器scripts/run_chunk_interleaved.py --experiment interleaved --stage preflight/gpu，冻结CPU报告、方案/启动器、既有源码、两素材和10模型资产SHA，全部新run_id。完成后源码/证据/门禁审计、重复临时内容清理与轻量交接备份。
