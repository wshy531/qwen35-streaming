# 分阶段耗时对照预登记

2026-10-10。固定洗手前四帧真实1 FPS、明确192×256，复用已验证FP32协议。只测有限输入的阶段延迟，不声称摄像头实时、吞吐或长时间稳定。

CPU分别测前四帧的顺序解码，以及完整/成对预处理与位置构造（各5次，中位数/范围；没有新视频文件）。CPU微型权重还检查完整/增量语言、独立存储的fork、固定问题分支后主缓存不变、reset清空和计时输出。

GPU单载入，载入前free≥5.5GiB、可用RAM≥3GiB，转FP32前≥2GiB；IEEE matmul/conv和math SDPA。预先构造GPU输入，不在视觉计时内搬CPU或存哈希。每个路径先1轮预热，再交错5轮正式测量，用同步墙钟与CUDA事件，列全部原始值和中位/范围。CUDA事件也包含提交间隙，不冒称纯算术时间。

视觉三路径：原整段4帧、候选整段4帧、原单元路径逐对2+2（候选在单时间单元上同原路径；每轮2次视觉）。候选临时方法安装/恢复时间另外测，不混进视觉计算。为语言准备一次候选特征，不重复编码。

语言在**同一份实际特征**上比较：一次完整前缀与“固定提示前缀+第一对+第二对”三个增量调用，包含各自lm_head；同步墙钟单列提示初始化、第一对、第二对。每轮重新清空状态，容量≤256，前缀/问题/固定单Token总容量预检。首预热轮按既有严格logits和四种缓存allclose1e-4门槛验证完整/增量；全程主cache的问答前后逐位不变。fork复制、固定Q1问题后缀prefill、一个预定HANDS Token续接、reset分别计时。**不生成答案、不计正确率**，固定Token步骤不代表模型选择了HANDS。

真实预算（首GPU预算触发后修订）：25视觉（预热4+正式20+语言特征准备1），候选内部Linear≤1300，即50个真实视觉Linear×26时间单元（6轮每轮完整2+逐对2，加准备完整2）；36语言（6轮×完整1/增量3/问题1/固定续接1），生成0，模型载入1，600秒看门狗。CPU须根据真实config的12块×4+merger2核对50与1300，不能用微型1块的操作数替代。首版1250少算准备完整的一个单元，原方案快照和失败保留。预计CUDA allocated≤5.5GiB，总峰值记录；额外留存视觉特征≤8MiB硬限，语言logits/cache/比较工作区归入总CUDA峰值，不能宣称所有附加内存≤8MiB。每轮丢弃输出与分支，缓存仅保留同输入对照所需；结束释放。异常时traceback可能在进程退出前引用Tensor，不将删除局部model变量误称为显存已释放。无集群/训练/新权重。
