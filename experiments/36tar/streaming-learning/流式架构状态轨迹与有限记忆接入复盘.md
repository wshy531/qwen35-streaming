# 流式架构状态轨迹与有限记忆接入复盘

日期：2026-10-12。本段按架构学习目标实施，进度只读《实验总纲.md》。历史识别/数值失败继续保留，没有训练或更换权重。

## 学到了什么

第一段将“模型保存状态”变为可观察轨迹：6个合成画面、官方处理器、真实执行的2层微型随机CPU模型，记录9步骤的Token数、下一位置、四类缓存形状和哈希。
单帧只等待，完整对写入；fork缓存存储独立、问答主状态不变；reset全部清空，之后从新状态开始。随机回答没有语义意义。
产物：`runs/architecture_trace_cpu_20261012_01/trace.html`及`trace.json`。

第二段把既有诊断候选变成通用入口可选模块：活动源码`streaming/frame_memory.py`、`streaming/remembering.py`，由`--remember-history`显式启用，默认关闭。

```text
完整真实新帧对 → 原视频主状态（KV / 卷积 / 递归）→ 当前问答fork
       │                  │容量满：全部reset
       └→ 有限CPU真实帧库（独立，不随上述reset清空）
                     │明确时间，且确有保留画面
                     └→ 新建独立历史问答会话 → 回答 → 释放
```

这次新增的是系统记忆层与查询路由，没有改模型层数、权重或S4混合续接运算。帧库最大3对/864KiB持久RGB，按帧对采样并FIFO淘汰；较大方形帧可能先达到字节限额，实际保留少于3对。
持久像素上限不包括模型/解码器/查询工作区；原子存入可暂时多持有一对，取回另有一对副本。当前程序关闭会释放帧库，不是磁盘持久记忆。

查询必须明确目标时间；只取覆盖该时间的保留帧对，不用最近画面冒充。帧对间空隙、已淘汰、单帧EOF未保存会表示无证据；未来时间表示尚未观察。无证据不调用模型。不是事件语义检索、记忆森林或无限历史。
历史会话共享权重但拥有独立缓存；查询结束及异常退出恢复模型RoPE副状态，主视频KV/卷积/递归不写入历史问题答案。
页面分别显示主记忆起点、外部覆盖区间/字节/淘汰和历史回答证据。CLI目前预先给定目标时间，文件结束后查询；程序接口可运行中调用，另有CPU续接契约验证，不声称已实现实时交互聊天。

## 真实运行与能力边界

为展示跨reset的区别，使用已有犬/鸽/猫各2帧，等比补边、无损FFV1组成6帧受控视频。犬从已有素材采样序号12开始，跳过片头；来源实际PTS与SHA保留，会话0..5秒明确为合成时间，不是自然事件先后。
重新解码6帧逐像素/PTS完全相同。有效视频205,060B，SHA256 `d7687677253bcdc250d4f28c6e89d0b2aa88e503e1390d671a5492f05d1fba6f`；只在本机，不进Git/备份。最初误选片头的资产和预检失败摘要保留。

当前问与历史问同为`Name the main visible animal.`，每次最多16Token，总200Token、主预算88、2帧首问。6帧共2次capacity reset，最后主状态只从4秒开始；独立帧库仍保留0–1、2–3、4–5秒。

| 路径/证据 | 实际流式回答 | 未改模型同输入回答 | 判断 |
|---|---|---|---|
| 当前0–1秒：犬 | The main visible animal is a dog. | 同一生成IDs | 本受控犬画面正确 |
| 当前2–3秒：鸽 | A dog. | 同一生成IDs | 误认保留，原模型也误认 |
| 当前4–5秒：猫 | A cat. | 同一生成IDs | 本受控猫画面正确 |
| 重置后取回0–1秒 | The main visible animal is a dog. | 对应原犬输入同一IDs | 提供了主状态已失去的旧证据 |
| 重置后取回2–3秒 | A dog. | 对应原鸽输入同一IDs | 取回正确，不代表识别正确 |
| 请求1.5秒/99秒 | 无证据拒答，0模型调用 | 无对应模型生成 | 不替换为其他画面 |

只有3个独立输入；3当前+2历史共5条生成记录不能算5个独立能力样例。同输入同答没有掩盖价值：最后主状态看猫，外部路由能再提供旧犬画面。不同可用证据得到不同回答，权重没有变化。
两次历史生成主四类状态逐位不变；未改源码独立GPU原对照3输入/3当前与2历史对应生成IDs全部相同。不能据此声称一般准确率提高、长期理解或所有数值等价。

真实流式GPU70：5视觉/45语言/35词表行，峰值allocated3.28249/reserved3.61719GiB，含载入6.567秒；未改原模型GPU71：3视觉/20语言。两进程顺序运行；这些不是速度比较，也不用于宣称显存降低。
CPU通用预检43契约通过；原同输入微型fresh prefill3组逐位通过。完整167项CPU回归及额外运行中历史问答后继续4帧/2reset契约通过，源树前后不变；这些是微型模型和软件契约，不是额外真实权重能力样例。

## 复现与下一架构问题

从个人发布目录运行；先准备自己视频，改变素材/参数/源码后必须fresh CPUproof。以下是本机实际参数，out须使用不存在的新目录：

```powershell
$common = @('--video','E:/VIT Model/datasets/history_integration_v1_02/controlled_six_frames.mkv',
  '--model-dir','E:/VIT Model/models/Qwen3.5-0.8B',
  '--question','Name the main visible animal.','--answer-tokens','16',
  '--max-tokens','200','--duration','10','--max-frames','6',
  '--first-qa-frames','2','--qa-every','2','--wall-seconds','600',
  '--remember-history','--memory-every-pairs','1',
  '--history-time','0.5','--history-time','2.5','--history-time','1.5','--history-time','99',
  '--history-question','Name the main visible animal.')
python scripts/run_video_demo.py --stage preflight @common --out <新的CPU目录>
python scripts/run_video_demo.py --stage gpu @common --preflight <上述CPU目录> --out <新的GPU目录>
```

尖括号内容须替换，不是字面参数。默认不加记忆选项仍走原有路径；GPU先核RAM≥3GiB、显存≥5.5GiB、转换空间≥2GiB，单模型，600秒硬看门狗。原对照使用独立240秒看门狗及新CPUproof，不复用其他输入的证明。

下一值得学习的问题是有限容量下“保留哪些证据、明确如何忘记”，先看覆盖与淘汰，再考虑分层锚点或事件检索；不能把流式执行变成更强识别能力，也不因鸽误认就默认训练。当前CLI非实时问答，长期语义检索、压缩、森林、BF16、摄像头和自然长时视频仍另行设计。
