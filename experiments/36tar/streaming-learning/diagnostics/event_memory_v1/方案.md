# 事件组织与真实代表保留：预登记方案

本方案冻结后先CPU预检再GPU，持续进度只读根《实验总纲.md》。

问题：同格跨时间平均可能把不同主体/动作混在一起。固定最多144个视觉Token，比较FIFO最近三对、现有ShortLongMemory均值、视觉变化分组保留真实代表。动物另有人工边界诊断臂（只供解释，不是在线候选）。本段不改变空间压缩，所有代表48Token完整网格。

调试犬12–15/鸽0–3/猫0–3秒六对，阈值算法只看五个相邻投影均值的余弦距离，排序后最大间隙中点。最大间隙不足1e-6固定回退0.1。没有标签/QA参与阈值，没有留出调参。阈值不承诺泛化。

动物留出犬20–23/鸽8–11/猫4–7（样本序号，真实PTS另保留）与调试不重叠，三种顺序复用相同六对特征；合成会话PTS0..11明确标记，不当自然事件。三题current/early/order、四臂共36问答。标签只用于事后主体检查，人工边界0/2/4仅诊断。

自然输入两已有独立源文件，各真实1FPS样本6..17共12帧：clean_hands与hand_hygiene。保持源真实PTS，不拼接、不倒序；三臂末尾三题共18问答，编码第四对时三臂current后续写两对共6问答，总60。来源/署名沿用原数据manifest，交付不含媒体。动作/顺序按可见画面作定性审阅，不能以EOS当答对；这两文件不是从未见过的盲测数据。

事件银行近期一对、长期最多两个已结束组，已到达的新旧相邻对的池化特征作变化判断；发生变化才把上一组的最后一真实对和标量范围写入长期。当前组内只保最新对，不重复占用历史槽位。超额淘汰最旧组，明确丢失。不保所有子张量或永久检测向量。一个组的跨度不是整段内容保证；QA只用真实代表的原时间/位置，绝不把代表画面伪标成完整区间。精确查询只在实际代表对时间内可用，未来/只剩组范围一律程序拒绝、不调用模型。

同预算指视觉Token上限相同，实际使用可以不足144，绝不补重复Token；事件检测临时均值向量最多两条1024维，共8192B，无永久辅助Tensor。单银行驻留≤592704B，原注册596800B上限不放宽；临时输入/导出/复制分别审计，所有比较CPU特征≤16MiB。组标量元数据有界；不保存无界trace到银行，run日志另计。

首轮CPU01的两项测试暴露了当前组提前占历史槽的调度错误，失败目录保留。上述关闭组写入规则是修订02，尚无真实模型回答参与修订；新CPUproof必须重做，不能复用01。

GPU预算1载入/24视觉/60问答/1920生成/2200语言forward/512总Token/480秒；CPU微型模型只验证接口和布局。原RAM≥3GiB/GPUfree≥5.5GiB、转换余量≥2GiB，FP32 IEEE/math，原门槛不降。GPU前proof绑定新目录全部源/计划/cases、80core及依赖、模型10资产和源视频SHA/像素/布局。分支规则通过--branch指定，拒main/master/空；源proof绑定该参数。一次模型、无训练/新依赖/集群/摄像头。

成功标准分开：因果/限额/所有权/未来拒绝/问答隔离/查询后续接是机制；旧主体可见覆盖和回答正确性是能力。若分组失效或回答不改善，保留完整失败，不按留出结果改阈值、题目或空间压缩。人工边界优于在线说明分段需改善；代表齐全仍答错说明需查识别或读入协议，不能立刻训练。
