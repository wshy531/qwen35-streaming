# 同预算保留策略小对照

当前FIFO记忆只留最近3对；候选保第一采样对作为锚点，其他空间留最新2对。都是3对/864KiB持久RGB；若字节预算连首对+新对都放不下，明确放弃首锚点而保最新，不声称锚点永远保留。
独立候选模块，不修改活动核心/默认策略/权重，没有语义选择或记忆森林。
CPU契约：同总覆盖的早期/近期取舍、字节不足放弃锚点、复制只读/未来拒绝、输入拒绝与clear、稀疏采样未满相同。
已有犬24帧（采样起点12）、鸽16帧、猫8帧，1FPS真实源，等比192×256，同实际输入同时更新两帧库。每源最终查询所有帧对中点，分别记录最早/最近3对和总留存；没有调用真实权重，不能计算动物识别准确率。
另单微型随机模型串行2策略：8帧后问0.5秒，再继续2帧，验证取回/拒绝和主状态隔离、继续/reset/关闭清空。微型模型回答无语义意义。
预算：0GPU/0训练/无新下载；48已有源帧+20合成微型帧，最多2帧库同时各864KiB持久像素，存入/取回另有一对临时副本；预训练真实权重不载入。小段上限沿用前窗口00:24:01，不新增时间窗口。
具体结果和持续计划仅以本机《实验总纲.md》为准。
