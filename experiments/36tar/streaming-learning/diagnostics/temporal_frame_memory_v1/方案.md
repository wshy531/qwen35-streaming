# 时间索引画面记忆候选：预登记

2026-10-12两小时窗口。本候选由既有容量reset明确丢失早期证据触发；停止特定动作题调参，固定通用主体/历史问题。资料依据见根通用流式纠偏与文献选择.md。借鉴短期/长期分离和取回证据，不复制论文架构，不称记忆森林/ReKV复现。

每个会话为三个来源各8真实帧的受控拼接：犬源12–19秒、鸽源0–7秒、猫源0–7秒；次序犬→鸽→猫、鸽→猫→犬、猫→犬→鸽。模型输入的frame ID与会话时间重新编号单调，源实际ID/PTS/像素指纹另存，明确非自然事件先后。所有三排列和问题在真实GPU前固定；素材已人工看过，有限受控架构诊断不是新留出榜单。

不改主混合状态。持续看24帧，288总Token/96问题/16答案/FP32/letterbox；容量reset正常发生。每第四个完成的真实成对帧存CPU RGB锚点、时间、ID，最多3对/6帧、884736B（864KiB）持久像素；FIFO超限淘汰。取回返回副本，解码/查询工作内存另计，不把像素字节当进程总RAM。这里存原采样真实画面，不存推测文字/自动事件标签/权重/任意递归状态。每会话clear，不泄漏前一会话。

末尾三个条件：主状态当前题`Briefly identify the main subject visible now.`；主状态历史题`What main subject was visible in the first two frames of this session? Answer briefly.`；对同一历史题从时间0锚点取回最初两帧，独立临时流式问答分支重新编码。原模型另臂独立whole prefill看与各条件相同的实际画面/模板/位置/问题。候选比主状态多看到了被保存的旧证据，有额外视觉计算，不能把差异称同输入模型能力改善。

检索缺失控制：时间4.5在已观察但未存区间，必须明确not_retained并拒绝，未来时间100必须not_observed并拒绝，不拿最近画面猜，不调用模型。只提供精确时间索引，不自动从自然语言推断任意事件时间，不保证覆盖全部历史。预定第一主体期望犬/鸟/猫，当前主体期望猫/犬/鸟，宽泛正确主体即可；允许bird/pigeon，不能精确品种过度评分。

新CPU：7条ownership/因果/淘汰/硬限/拒绝/clear契约，3会话主状态隔离及独立9输入原/成对逐Tensor和原/修改随机fresh prefill；随机答案无能力含义。新GPU每臂1载入/240秒外部看门狗；流式最多42视觉/600语言/144生成（9答）、原最多9视觉/153语言/144生成。RAM≥3GiB/显存空闲≥5.5GiB/转FP32空闲≥2GiB，单模型顺序，不降门禁。最多3受控会话72帧，不保存大Tensor；字节/主四状态/计数、输入来源/记忆覆盖/拒绝、额外计算与耗时均记录。参数/源码改变重做CPU，旧结果不改。

候选是否进入默认系统取决于证据与代价。本实验没有语义检索、事件树、KV压缩、训练、自然长片或无限记忆证明。
