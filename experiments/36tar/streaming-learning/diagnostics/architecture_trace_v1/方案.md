# 六帧混合状态轨迹

目的：用真实执行的CPU微型随机模型讲清流式状态，不评估语义或性能。
输入：官方本地处理器，6个合成32×32 RGB画面，无媒体下载。
预算：仅1个微型模型，0真实权重载入、0GPU；6帧/3视觉写入/1次问答最多2生成Token/1次显式reset。
验证：首帧只等待；完整对更新状态；fork四类张量不共享存储；问答主状态指纹不变；reset全部为空；后两帧建立新epoch。
产物：标量/哈希/形状trace.json与通俗trace.html，不存Tensor或画面。
命令：项目Python运行本目录trace.py，指定--model-dir和独立--out。
具体完成状态与结果只以本机《实验总纲.md》为准。
