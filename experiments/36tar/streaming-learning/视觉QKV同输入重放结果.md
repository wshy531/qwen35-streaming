# 第一视觉层QKV同输入重放：固定结果

2026-10-10，s4b_qkv_replay_preflight_20261010_01及s4b_qkv_replay_gpu_20261010_01均完成exit0/未超时。进度只在实验总纲.md维护。

实际首层norm1输入SHA与先前完整视觉捕获一致。只运行视觉前缀一次，随后在相同输入/相同QKV权重和偏置下执行9次局部线性运算，完整视觉forward0、语言0、生成0。整段/两半输出SHA精确复现前轮对应捕获。

| 对照 | 逐位相同 | 最大差 |
|---|---|---:|
| 原FP32完整重复 | 是 | 0 |
| 原FP32，384行 vs 两次192行 | 否 | 8.58306885e-6 |
| FP32两半零填充为384行并切回对应行 vs 完整 | 是 | 0 |
| 局部FP64运算后转FP32，整段 vs 两半 | 是 | 0 |

权重/偏置前后SHA相同。该固定投影的差异可由计算形状改变触发，恢复同形状或用局部高精度可消除这一差异；不能推断具体CUDA内核或后续所有算子只有一个原因。FP64参考输出与原FP32完整输出也不逐位相同，不能说提高精度不改变原结果。

峰值GPU allocated3.2206GiB；保守诊断缓冲119.75MiB，未超128MiB。实际耗时/资源、原输出对FP64参考误差和清理见qkv_replay_summary.json/cleanup.json，子进程已退出，没有Tensor落盘或训练。零填充与FP64均为局部诊断，不是部署方案。

后续探索：可逆地让视觉线性层按相同时间单元执行，测试成对/整段编码是否一致，独立报告该候选对原完整视觉的偏移。原默认路径及失败不变。
