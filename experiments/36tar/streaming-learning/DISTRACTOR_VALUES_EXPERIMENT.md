# 无关视觉特征会不会干扰历史问答？

2026-10-14固定结果快照；持续进度以《实验总纲.md》为准。没有新素材、训练、压缩或默认模型改动，综合汇报未改。

**这轮确认了局部因果证据：文字、长度、位置和目标特征全部不变时，只替换无关节点的视觉值，就能恢复此前两项错误的猫毛色回答。** 这支持选择相关证据后再读的路线，但仍不是通用检索或识别能力提升。

## 为什么还需要这一步

上一轮发现，单独给旧猫能答深色；给完整“猫→狗→洗手”却答浅色；按时间取回猫后恢复。这个变化可能来自删掉了无关视觉内容，也可能来自上下文变短、时间文字或位置变化。不能只因删减后答对，就断言是另一只狗在干扰。

所以，这次不删节点：五个全历史条件始终保留3个节点、144个视觉Token，固定全部文字ID、四轴位置、长度、节点元数据、质量、来源坐标，以及目标节点自己的视觉值。只改变指定无关槽位的视觉值。

## 我们改了什么

新增独立`diagnostics/distractor_values_v1`。数据、问题、原读取器都沿用GPU95，修改只在诊断副本的`choose()`中。

对每个问题，三个槽位分别是目标动物T、另一旧动物O、近期洗手R。它们在真实序列中的先后随问题而定；程序按目标索引选择受控槽位。

| 条件 | 改什么 | 保持什么 |
|---|---|---|
| 原全历史 | 不改 | 原始144Token读取参考 |
| O→R | 无关旧动物的值换成洗手值 | 目标与全部文字/位置等不变 |
| O→T | 无关旧动物的值换成目标副本 | 同上 |
| R→O | 近期洗手的值换成无关旧动物值 | 同上 |
| O↔R | 互换两个无关槽位的值 | 同上，视觉值集合也未增删 |
| 单目标 | 只给目标48Token | 不同长度参考，不能用于本轮固定布局因果比较 |

关键操作类似：

```python
selected = [
    replace(slot,
            features=nodes[donor].features.clone(),
            mass=slot.mass.clone(),
            coords=slot.coords.clone())
    for slot, donor in zip(nodes, donor_by_slot)
]
```

没有使用零向量或均值伪造一个“空画面”。替换值来自同一例中已经计算的真实视觉特征。但复制/互换后组合仍是人工反事实，不能称为真实发生过的视频。结果记录带每槽位donor map，明确区分原槽位元数据与替换值来源；真实银行和主视频状态不改。

四组熟悉来源的受控序列，每组3题、6条件，共72次真实问答。保留每例主状态显式reset后的独立问答流程。两组猫窗口不同，但均为已有来源和熟悉样例，不算独立新视频泛化。

## 效果是什么

最关键的是开发组和第二组固定窗口的“猫在前，问0.5秒猫毛色”两题：

| 条件 | 开发窗口 | 第二固定窗口 |
|---|---|---|
| 原全历史 | 浅色✗ | 浅色✗ |
| 无关狗→洗手 | 深色✓ | 深色✓ |
| 无关狗→目标猫副本 | 深色✓ | 深色✓ |
| 洗手→无关狗 | 浅色✗ | 浅色✗ |
| 无关狗与洗手互换 | 浅色✗ | 浅色✗ |
| 单目标参考 | 深色✓ | 深色✓ |

在全部12项相关目标事实检查中，原全历史8项正确；O→R、O→T各10项；R→O与O↔R仍各8项；单目标10项。只有这两项毛色发生语义变化，没有把标点差异算成新增正确。反事实条件的数字只描述目标事实在人工上下文中的可读性，不是实际历史问答准确率。

用通俗的话说：我们没有缩短题目，也没有移动书签，只是把旁边另一张动物信息卡换掉，答案就恢复了。因此，这两例里不能再把改善仅归因于“少了几个Token”或“位置变简单了”。

进一步看，狗仍在上下文中、只是换了槽位时，错误仍在；把狗信息再复制一份也没有改善。这与“无关狗的视觉内容参与干扰”相符。不过，狗特征同时包含主体、颜色、草地、人物、背景等信息，替换它并不是只修改毛色。我们还没有定位到具体语义因素、注意力头、Gated DeltaNet递归状态或网络层。

## 没有改善什么

第二组猫的主体，在单节点未压缩时就会被认成狗；这轮各种无关值替换仍未修复。它属于目标内容自身的读取失败，不应混入这次毛色干扰的收益。

本轮也没有新增一种实用的“把狗换成猫”的存储算法。替换特征只是用来定位原因，不能在真实问答时改写事实。实用候选仍是上一轮的受限时间选择：取对应证据、保留来源、在独立上下文回答。

## 对下一步的决定

当前这条诊断链已经回答了一个具体问题：**既有保存/状态链路之外，读取时送入哪些视觉证据，会影响本来可答的历史事实；无关视觉值确实能参与本例干扰。** 继续增加几何掩码或反事实变体，暂时不如把已验证的读取路径做成可用入口。

下一段建议将严格时间查询接入一个可选视频文件入口，显示所取帧对的时间范围、保留/淘汰情况以及无证据返回；保持默认路径和原始事实不变。先完成连续输入、主reset后的取回、缺失时间拒绝的端到端验收，再考虑扩展问句或接入有损森林节点。任意语义检索和基础识别提升仍各自需要证据，不能由本轮两项恢复代替。
