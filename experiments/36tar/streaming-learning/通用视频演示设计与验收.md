# 通用视频演示：设计与本轮预算（2026-10-11）

目标是让视频路径、自然语言问题、采样率、视频时长上限和帧预算可配置；显示原比例画面、实际视频PTS、回答、容量重置次数及当前记忆起点。保留原23帧脚本和全部历史记录。活动源码唯一入口是 `publish/qwen35-streaming/experiments/36tar/streaming-learning/code/qwen35-streaming-s4`，旧 `E:/VIT Model/code` 只读。Git仍在36tar个人分支，main不推送。

本版本同步读取文件，不按墙钟模拟实时，不接摄像头，不承诺跨重置记忆。最大帧/时长明确有限；结束原因区分文件EOF、视频时长上限和帧预算。问题不进入视频主状态。视频时间由解码PTS确定，采样仍因果且顺序；变化的帧形状显式拒绝，不能默默更改协议。

保持宽高比缩放至192×256以内并居中补黑边；补边后的固定画布遵守官方处理器patch/merge约束。原脚本默认stretch用于历史复现，新入口显式letterbox。补边会改变模型实际视觉输入，理解质量须另做评测。

HybridSequence新增full/last/none输出选择，默认full保留数值接口。通用视频写入选none；问题prefill和生成选last；数值证据接口仍保留full。CPU对照检查四类状态逐位一致、续接一致及最后位置预测容差；不能仅凭省略词表投影宣称端到端提速。

实时页面仅绑定127.0.0.1，保留一个小JPEG和最近8条回答，无视频队列、GPU张量或缓存副本堆积。每次回答临时复制主缓存核验隔离后释放。事件流写JSONL，有限预算内只保留标量触发日程，用于CPU/GPU输入一致性检查。结束保存viewer.html供离线查看，显示末画面和最近回答；它是运行记录，不是仍在推理的后台服务。

新启动器默认允许任意非main/master、非detached的协作分支；可重复传入 `--allow-branch` 收紧允许名单。GPU必须重跑同输入、同参数的CPU预检，核源码及启动器SHA、全部10模型资产、视频SHA、CPU结果、预算和触发日程；旧机器proof不能借用。父进程watchdog包含加载在内，超时结束子进程；失败证据保留。新输出目录必须不存在。
