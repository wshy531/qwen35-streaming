# 猫毛色退化：平均、Token选择还是位置？

2026-10-14，本轮GPU91完成。继续定位上一轮的黑白猫毛色错误，比较同样48视觉Token下的融合、原目的Token子集、完整真实帧对，以及固定值的位置干预。默认实现保持，本轮不写入综合汇报。

## 最关键的结果

| 读取方式 | 视觉Token | 原猫视频的毛色 | 原猫视频的主体 |
|---|---:|---|---|
| 原两对完整特征 | 96 | dark，正确 | cat，正确 |
| 完整第一帧对 | 48 | dark，正确 | cat，正确 |
| 完整第二帧对 | 48 | dark，正确 | dog，错误 |
| 融合后的目的Token | 48 | light，错误 | cat，正确 |
| 原目的Token，不做平均 | 48 | light，错误 | cat，正确 |
| 融合值放到首对完整网格 | 48 | light，错误 | cat，正确 |
| 原目的值放到首对完整网格 | 48 | light，错误 | cat，正确 |

因此，当前错误不能只归因于加权平均：完全不做平均、只取相同的目的Token子集，也会答错毛色。保留一整对真实特征则在同48Token预算下能读对；完整帧表示与保留哪些Token值得优先研究。

这仍不是最终归因。首/末完整帧对的真实时间标签与位置不同于融合区间，对比不是纯粹只换特征值。一次人为网格干预失败，也不能排除所有可能的位置适配问题。最准确的结论是“平均不是这次失败的必要条件”，不能说平均完全无害，或者颜色已经不可恢复。

## 怎样区分值和位置

把96Token按交错规则分成源和目的，原合并规则最终保留48个目的位置。构造如下2×2：

| | 保留真实目的位置 | 应用首对完整6×8网格 |
|---|---|---|
| 按原规则融合的48个值 | 原融合路径 | 只改位置 |
| 48个原目的值，不平均 | 只改值 | 值与位置控制的另一格 |

固定位置比较时，输入Token及四轴位置逐位一致，只有插入的视觉特征不同。固定值比较时，视觉特征及提示Token逐位一致，只修改视觉Token的应用位置；问题位置保持。节点保存的原来源坐标没有改写，人为应用网格另外标记，不能冒充真实融合来源。

```python
# 不做平均的目的值；目的坐标与原合并结果完全一致
destination_values = torch.cat([first.features, second.features])[1::2]

# 位置干预保留这些值，单独改变应用RoPE
t = first_pair_grid_base
h = first_pair_grid_base + row
w = first_pair_grid_base + column
```

融合节点mass总和96，未融合子集mass为48；mass只是存储元数据，在这条语言读取路径不进入注意力权重。因此这里不是以改变mass来让模型回答。

## 同为猫、不同毛色的新控制

加入两张在模型测试前选定的真实照片：

- [黑猫照片](https://commons.wikimedia.org/wiki/File:Black_cat_laying.JPG)：Cep21，来源页PD-self。黑猫在较亮的背景前。
- [浅色猫照片](https://commons.wikimedia.org/wiki/File:White_cat_in_black_background.jpg)：Shadman.aousaf，来源页CC BY-SA4.0。浅色猫在黑背景前，是黑白摄影，只检验明暗而非色相。

两张原JPEG合计204562字节，原始大小/SHA1与来源页匹配，另存SHA256、作者、许可和URL。原图未编辑，模型预处理仅等比补边到256×192。每张重复4帧，组成两对静态控制；不是自然运动视频，媒体不进入Git和交接备份。

新控制两张都是猫，模型在7种方式下都分别回答dark/light，并认出cat，共28次相关问答均符合这两个粗标签。重复照片的两次视觉投影逐位一致，也证明这不是后来帧引入新内容导致。

这降低了根据物种猜毛色、根据整幅画面亮度猜毛色的解释，但背景、姿态和照片风格仍不同。两张静态图也不能代表复杂运动视频泛化。它们没有复现原猫视频的毛色退化，说明退化与输入和特征选择有关，不是所有48Token读取都必然失败。

## 完整帧对方案的作用和边界

第一对是源0..1秒，第二对是2..3秒，元数据保留各自实际覆盖范围。首对只保存实际看见的这一对，不把整个0..3事件伪称为完整保留。

保完整首对能在这个案例中同时保持颜色和主体，但舍弃其他时刻，可能漏掉中途动作。第二对保持毛色却误认成dog，说明简单选择最后一对也有风险。当前只能说明完整代表是值得与融合比较的方案，不能宣称首帧对总是最优。
